    1A harder goal

    The new goal: find a city on our list that's at least 25 °C and dry, so we can go to the beach.

    The temperature alone can't answer that, so the agent gets a second tool that says whether a city is rainy or dry. Now each step, the brain decides two things: which city to look at, and which tool to use on it.

    2The agent

    Here's the whole agent. Compared with the Intro, it has a second tool, a second set of notes, and a brain that names the tool it wants. Run it.

    In [1]
    cities = ["Boston", "Miami", "Phoenix", "Denver"]
temperatures = {"Boston": 4, "Miami": 27, "Phoenix": 31, "Denver": -3}
rain = {"Boston": "dry", "Miami": "rainy", "Phoenix": "dry", "Denver": "dry"}

def get_temperature(city):         # TOOL 1: looks up the temperature
    return temperatures[city]

def get_rain(city):                # TOOL 2: looks up rainy or dry
    return rain[city]

def brain(temps, rains):           # BRAIN: picks a tool, or answers
    for city in cities:
        if city not in temps:
            return "check temperature", city
        if temps[city] >= 25 and city not in rains:
            return "check rain", city
        if temps[city] >= 25 and rains[city] == "dry":
            return "answer", city

temps = {}                         # NOTES: temperatures found so far
rains = {}                         # NOTES: rain found so far
while True:                        # LOOP: decide, act, remember, repeat
    action, city = brain(temps, rains)
    if action == "answer":
        print("Go to", city)
        break
    if action == "check temperature":
        temps[city] = get_temperature(city)
        print(city, "is", temps[city], "°C")
    if action == "check rain":
        rains[city] = get_rain(city)
        print(city, "is", rains[city])
    Boston is 4 °C
Miami is 27 °C
Miami is rainy
Phoenix is 31 °C
Phoenix is dry
Go to Phoenix

    It checked the rain only in Miami and Phoenix, the two cities warm enough to matter. It never asked about rain in Boston, and it never looked at Denver at all.

    • Tools: get_temperature and get_rain, one question each.
    • Brain: goes through the cities in order. If it doesn't know a city's temperature, it checks that. If the city is warm, it checks the rain. If the city is warm and dry, it answers.
    • Notes: one dictionary for each tool, temps and rains.
    • Loop: runs whichever tool the brain picked and writes the result in the right notes.

    4Tools in real AI agents

    Our brain knows its two tools because we wrote rules for each one. A language model learns about its tools from short descriptions, like "get_rain: tells you whether a city is rainy or dry", and picks one the same way: from the goal and what's already in the notes. Real agents often have dozens of tools, and picking the right one is a big part of what makes them useful.
