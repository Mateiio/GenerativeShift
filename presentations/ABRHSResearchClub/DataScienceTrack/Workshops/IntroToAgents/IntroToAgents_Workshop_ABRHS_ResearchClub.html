1What is an agent?

Our agent's goal: find a city on our list that's at least 25 °C today, so we can go to the beach.

It can't know the answer in advance. It has to check cities one at a time and decide after each one whether it's done. For that it needs four parts: a tool to look things up, a brain to decide the next step, notes to remember what it found, and a loop that keeps going until the brain answers.

The brain is an LLM. Each time around the loop, the agent asks it what to do next.

2The agent

Here's the whole agent. Run it and watch what the LLM decides.

In [ ]
from google.colab import ai         # Colab's built-in LLM: free, no API key

cities = ["Boston", "Seattle", "Miami", "Denver"]
temperatures = {"Boston": 4, "Seattle": 9, "Miami": 27, "Denver": -3}

def get_temperature(city):          # TOOL: looks something up
    return temperatures[city]

def brain(notes):                   # BRAIN: asks the LLM for the next step
    prompt = f"""Goal: find a city from {cities} that's at least 25 °C today.
Temperatures you've looked up so far: {notes}
If one of them is at least 25 °C, reply: answer CITY
Otherwise reply: check CITY, picking a city you haven't looked up yet.
Reply with exactly two words, like: check Boston"""
    reply = ai.generate_text(prompt).strip()   # the LLM call
    print("LLM:", reply)
    action, city = reply.split()
    return action, city

notes = {}                          # NOTES: what the agent has found so far
for step in range(10):              # LOOP: decide, act, remember (at most 10 LLM calls)
    action, city = brain(notes)
    if action == "answer":
        print("Go to", city)
        break
    notes[city] = get_temperature(city)
    print(city, "is", notes[city], "°C")

Each time around the loop, the agent makes one LLM call: it sends the goal and the notes, and the LLM replies with its decision, like check Miami or answer Miami. Everything else is plain Python.

  • Tool: get_temperature looks up one city.
  • Brain: brain writes a prompt with the goal and the notes, calls the LLM with ai.generate_text, and reads its two-word reply.
  • Notes: notes remembers every temperature found so far.
  • Loop: asks the brain, uses the tool, updates the notes, and stops when the LLM answers, or after 10 LLM calls no matter what.

4What the LLM actually does

The LLM never looks anything up. It only reads the prompt and writes two words back. Our Python code runs the tool, keeps the notes and runs the loop. Every AI agent works this way, from this one to the ones behind ChatGPT and Claude: the model decides, and code does the work.
